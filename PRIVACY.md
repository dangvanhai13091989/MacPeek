# Privacy Policy

Last updated: September 4, 2026

MacPeek is designed to perform its core work locally on your Mac.

## Data collection

MacPeek does not collect analytics, telemetry, advertising identifiers, crash reports, keystrokes, browsing history, or personal information. It does not operate an account system.

## Window thumbnails

Screen Recording permission is used only to create the window thumbnails shown in the Dock preview. Captured thumbnails are cached briefly in memory for responsiveness. They are not written to disk or uploaded.

## Accessibility

Accessibility permission is used to identify Dock items and to focus or close the window selected by the user. MacPeek does not record keyboard input.

## Network access

MacPeek contacts GitHub-hosted endpoints to check for and download signed software updates through Sparkle. Sparkle system profiling is disabled. Choosing **Support development** opens the donation page in your default browser; MacPeek does not receive or process payment details.

## Source code

The complete source code is available at <https://github.com/dangvanhai13091989/MacPeek> so these claims can be independently reviewed.
