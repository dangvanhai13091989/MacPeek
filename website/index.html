How It Works

Three steps. That's it.

01

Install & Grant Permissions

Drag MacPeek to Applications. Grant Accessibility and Screen Recording permissions in the guided setup.

02

Hover Any Dock Icon

Move your cursor over any app icon in the Dock. A live preview of its windows appears instantly.

03

Click to Switch

Click on any preview thumbnail to instantly switch to that specific window. Multitasking made effortless.

FAQ

Frequently Asked Questions

Why does MacPeek need Accessibility and Screen Recording?

Accessibility is required to detect which Dock icon you're hovering over. Screen Recording is needed to capture live window thumbnails. MacPeek never records or saves any screen content.

Is MacPeek safe? Why isn't it on the App Store?

MacPeek is fully notarized by Apple, meaning Apple has scanned it for malware. It's not on the App Store because the APIs it uses (Accessibility, Screen Recording) are restricted in the App Store sandbox. Many popular Mac utilities like Alfred, BetterTouchTool, and Bartender are also distributed outside the App Store for the same reason.

Does it work with multiple monitors?

Yes! MacPeek automatically detects which screen your Dock is on and positions the preview popup correctly on that same screen.

Is MacPeek really free?

Yes. Every feature is free and the source code is available under GPL-3.0.

How do updates work?

MacPeek checks the signed GitHub release feed daily and lets you install updates using Sparkle.

How can I contribute?

Report an issue, improve a translation, submit a pull request, star the repository, or support development.
