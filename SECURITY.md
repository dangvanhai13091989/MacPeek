# Security Policy

## Supported versions

Security fixes are provided for the latest published MacPeek release.

## Reporting a vulnerability

Please do not disclose a security vulnerability in a public issue. Use GitHub's **Report a vulnerability** feature in the Security tab of this repository. If that is unavailable, email `dangvanhai13091989@gmail.com` with the subject `MacPeek security report`.

Include reproduction steps, affected macOS versions, and the potential impact. You should receive an acknowledgement within seven days.

## Release security

Official releases are:

- built from this repository;
- signed with an Apple Developer ID certificate;
- notarized by Apple; and
- signed with Sparkle EdDSA for automatic-update verification.

Never install a build offered outside this repository or the official MacPeek website.
