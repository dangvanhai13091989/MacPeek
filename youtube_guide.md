## 📹 Cách quay màn hình (miễn phí, có sẵn trên Mac)

### Cách 1: QuickTime Player (Đơn giản nhất)

1. Mở **QuickTime Player**
2. Menu → **File → New Screen Recording**
3. Click mũi tên ▼ cạnh nút Record → chọn **"MacBook Air Microphone"** (nếu muốn thuyết minh)
4. Chọn **Record Entire Screen** hoặc kéo chọn vùng
5. Nhấn **Record** → thực hiện demo → nhấn **Stop** trên menu bar
6. **File → Export As → 1080p** → lưu file .mov

### Cách 2: Screenshot Toolbar (nhanh hơn)

1. Nhấn **⌘ + Shift + 5**
2. Chọn **Record Entire Screen** hoặc **Record Selected Portion**
3. Click **Options** → chọn **Microphone** nếu cần
4. Nhấn **Record** → demo → nhấn **Stop** trên menu bar
5. Video tự lưu vào Desktop

> **Tip:** Quay ở độ phân giải **1920x1080** hoặc cao hơn. Nếu dùng Retina display, video sẽ tự động 2K/4K.

## 🔧 Tips quay video chuyên nghiệp

### Trước khi quay:

1. **Dọn Desktop** — xóa hết file trên Desktop
2. **Đóng notifications** — System Settings → Notifications → Do Not Disturb ON
3. **Ẩn tên thật** — đổi tên máy nếu hiện ở đâu đó
4. **Mở sẵn 5-6 app** — Chrome (3-4 windows), VSCode, Safari, Finder, Notes
5. **Đặt wallpaper đẹp** — màu tối hoặc gradient
6. **Phóng to con trỏ** — System Settings → Accessibility → Display → Cursor Size (tăng lên cho dễ thấy)

### Khi quay:

1. **Di chuột chậm** — người xem cần thấy rõ
2. **Đợi 1-2 giây** sau mỗi thao tác — để popup render xong
3. **Không click linh tinh** — mỗi thao tác phải có mục đích

### Sau khi quay:

1. **Cắt phần thừa** — dùng iMovie (miễn phí) hoặc QuickTime Edit
2. **Thêm text overlay** — iMovie → Titles
3. **Thêm nhạc nền** — YouTube Audio Library (miễn phí, không copyright)
4. **Export 1080p** hoặc cao hơn
